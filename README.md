# ai-engineering

My structured path from zero to AI engineer. Built to actually understand what's happening, not "vibe" my way through prompts.

## The plan

This repo follows a 6-phase curriculum. Each phase has weekly folders with exercises and notes. I commit after every exercise so the git history shows real learning.

| Phase | Weeks | Focus |
|-------|-------|-------|
| 01 — Python basics | 1–4 | Syntax, control flow, data structures, file I/O |
| 02 — Python tooling | 5–8 | Git, virtual envs, APIs, packaging, testing |
| 03 — Data & ML foundations | 9–12 | NumPy, pandas, what models actually do |
| 04 — LLM APIs | 13–16 | Calling OpenAI/Anthropic, prompting, embeddings, RAG |
| 05 — LangChain | 17–19 | Chains, memory, retrievers, LCEL |
| 06 — Agents | 20–23 | Tool use, ReAct, agent frameworks |
| 07 — Capstone | 24+ | A real project I can show |

## How I work this

- One phase at a time. No skipping ahead.
- Every exercise gets a commit. Git log = proof of progress.
- If I'm stuck for >30 minutes, I write the question in `notes/stuck.md` and ask for help.
- I don't move on until the week's checkpoint passes.

- This is 4–6 months at 1–2 hours/day. Not a sprint.
