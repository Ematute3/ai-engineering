# Phase 1.5 — AI-Native Workflow (Weeks 1–2)

**Goal:** Stop larping. Set up Copilot, build real things, ship them.

This phase replaces the original Phase 2 of the roadmap. You compressed Phase 1 by using AI to write code. Now we make that the *default* way you work: AI drafts, you review, you understand, you ship.

## What you're actually learning this phase

| Skill | Why it matters |
|-------|----------------|
| GitHub Copilot setup & workflow | Your pair-programmer from now on |
| Prompting AI for code | Better prompts = 10x better code |
| Reading AI-generated code critically | AI is wrong ~20% of the time |
| Building a real CLI tool end-to-end | First project you could put on a resume |
| Setting up a GitHub Action | First taste of "AI in CI/CD" |
| Writing a README that doesn't suck | How people judge your work |

## Week-by-week

- **Week 1:** Copilot setup + first real project (CLI toolkit)
- **Week 2:** GitHub Action that uses AI to auto-review PRs

After this phase, you move into Phase 2 of the original roadmap — Python tooling, APIs, testing — but you'll do all of it with AI pair-programming baked in.

## The rule

Same as before: you don't move on until you can explain every line of what you shipped. AI writes, you read, I verify.

Start with [`week-1/setup/COPILOT.md`](./week-1/setup/COPILOT.md).
