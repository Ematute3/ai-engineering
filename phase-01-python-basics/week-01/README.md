## The 10 exercises

Make each one its own file. Name them `ex01_hello.py` through `ex10_*.py`.

### ex01 — Hello, you
Print exactly: `Hello, <your-name>!`
Use a variable for the name.

### ex02 — Age in days
Ask the user for their age. Print how many days old they are (assume 365 days/year, ignore leap years).

### ex03 — Tip calculator
Ask for a bill amount and a tip percentage. Print the total with tip.

### ex04 — Temperature converter
Ask for a temperature in Fahrenheit. Print it in Celsius. Formula: `C = (F - 32) * 5/9`.

### ex05 — Even or odd
Ask for an integer. Print "even" or "odd".

### ex06 — Bigger of two
Ask for two numbers. Print the bigger one. If they're equal, print "they're equal".

### ex07 — String reverser
Ask for a word. Print it backwards.

### ex08 — Initials
Ask for a full name. Print the initials in uppercase. Example: `evan matute` → `E.M.`

### ex09 — Mad libs
Ask for a noun, a verb, an adjective, and a place. Print a sentence using all four.
Example: `The <adj> <noun> <verb> into <place>.`

### ex10 — Receipt
Ask for 3 items with prices. Print a formatted receipt:
```
Item 1: $4.50
Item 2: $12.00
Item 3: $0.99
Total:  $17.49
```
