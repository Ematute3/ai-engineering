# Resources — what I'm actually using

I'm only listing resources I either own, have read, or plan to use for real. No infinite reading lists.

## Free, primary

- **CS50P — Harvard's intro to Python** (David Malan). YouTube + edx. The best beginner Python course. I'm doing weeks 1–4 alongside my own exercises.
- **Automate the Boring Stuff with Python** (free online). Great for "Python that does stuff."
- **The Illustrated Transformer** (jalammar.github.io). One read, then I close it. Best visual explanation of attention.
- **3Blue1Brown — Neural Networks** (YouTube). Visual, no math gatekeeping. Use this when I hit Phase 3.
- **Andrej Karpathy — Let's build GPT** (YouTube). 2 hours. Don't watch until Phase 3.

## When I'm ready to build, not learn

- **LangChain docs** (python.langchain.com). Reference, not a course.
- **Anthropic / OpenAI docs.** Same — reference, not a course.
- **Hugging Face course** (free). For Phase 3 if I want depth.

## Books I will buy ONLY if I finish the free version of the same thing

- *Fluent Python* (Ramalho) — for serious Python fluency, around Phase 2 week 7.
- *Designing Machine Learning Systems* (Huyen) — Phase 4, when I'm building real RAG.

## Anti-resources (avoid)

- "AI for Everyone" type courses that don't make you code
- 40-hour YouTube playlists
- Anything that says "no coding required"
- Twitter/X threads as a primary source
